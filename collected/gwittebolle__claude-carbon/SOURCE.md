# gwittebolle/claude-carbon

Copied from https://github.com/gwittebolle/claude-carbon (license: **MIT**). The upstream license file is kept in this folder. All credit goes to the original authors.

| Skill | Upstream path | What it does |
|---|---|---|
| [carbon-badge](carbon-badge/) | `skills/carbon-badge` | Generate a shields.io badge of your Claude Code carbon footprint for your READMEs |
| [carbon-card](carbon-card/) | `skills/carbon-card` | Generate shareable PNG report cards of your Claude Code carbon footprint |
| [carbon-panel](carbon-panel/) | `skills/carbon-panel` | Open the carbon pane, your CO2 molecule and the warming stripes of your sessions |
| [carbon-pr](carbon-pr/) | `skills/carbon-pr` | Post the development footprint of the current branch as a sticky PR comment |
| [carbon-report](carbon-report/) | `skills/carbon-report` | Display CO2 emissions report for Claude Code sessions |
| [carbon-update](carbon-update/) | `skills/carbon-update` | Update claude-carbon to the latest version (a clone install also re-prices its history, CO2-only) |
