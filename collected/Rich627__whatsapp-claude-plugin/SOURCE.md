Copied from https://github.com/Rich627/whatsapp-claude-plugin (license: **Apache-2.0**). The upstream license file is kept in this folder. All credit goes to the original authors.

| Skill | Upstream path | What it does |
|---|---|---|
| [access](access/) | `skills/access` | WhatsApp channel access — approve pairings, edit allowlists, set DM/group policy. Use when the user asks to pair, approve someone, check who's allowed, or change policy for the WhatsApp channel, an… |
| [configure](configure/) | `skills/configure` | Select linked-device or official Cloud API connection, configure a phone number, review access and manage linked-device authentication. |
| [doctor](doctor/) | `skills/doctor` | Diagnose WhatsApp channel problems — checks the server process, singleton lock, linked-device auth, access config, and optional features, then explains what's broken and how to fix it |
| [setup](setup/) | `skills/setup` | Choose linked-device or official Cloud API onboarding, then configure connection and access control |
