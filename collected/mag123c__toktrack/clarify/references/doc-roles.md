# Document Role Contract (Compounding SSOT)

To ensure future sessions measure rather than guess, distinguish the authority of each document.
**Reading order: DECISIONS → WRAP → PLAN/DRAFT.**

| Document | Role | Timing | Authority |
|------|------|------|------|
| DRAFT | Consensus building (thinking process) | Pre-planning | Low (may go stale) |
| PLAN | Execution contract (read by /implement) | Planning | Intent — not fact |
| WRAP | Plan↔reality reconciliation (what actually happened) | Post-implementation | Current fact |
| DECISIONS | Permanent why-ledger | Cumulative | Permanent truth |

- PLAN is a pre-implementation artifact → it mixes in assumptions. The source of truth for "what is fact" is not PLAN but **WRAP/DECISIONS**.
- No background duplication between DRAFT/PLAN — PLAN *references* DRAFT and does not restate it.
